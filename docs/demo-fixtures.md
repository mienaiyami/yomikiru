# Dev-only demo fixtures

Local reading corpus for gallery, scroll modes, and format coverage (EPUB / CBZ / CBR / PDF / image folders, long-strip vs paged, multi-chapter trees).

> [!IMPORTANT]
> **Developers only.** This library is **not** packaged with installers or portable builds. Never commit binaries under `demo/`. Do not add production code that auto-loads `demo/`.

## Legal

- Downloaded assets must be clearly open (see each manifest entry’s `license`).
- EPUBs are a curated subset of [IDPF/W3C EPUB 3 Samples](https://idpf.github.io/epub3-samples/30/samples.html) with clear grants only (mostly **CC-BY-SA 3.0**; Linear Algebra is **GNU FDL 1.2**). Excluded: O’Reilly-copyrighted *Accessible EPUB 3*, NC-licensed Kusamakura, and other ambiguous titles.
- Comic page images are public domain; the CBR sample is a PD Golden Age comic from Internet Archive.
- Synthetic pages are generated by the setup script (no third-party copyright).
- Licenses and source URLs are recorded in `demo/LICENSE-SOURCES.md` after setup.
- Do not add copyrighted manga/comics/books to the manifest or `demo/`.

## Setup

After installing dependencies:

```powershell
pnpm demo:setup
```

Optional: refresh pinned checksums after intentional URL/content changes:

```powershell
pnpm demo:setup -- --update-checksums
```

Then commit the updated `scripts/demo-fixtures.checksums.json` if hashes should be shared with the team.

The script prints the absolute path to `demo/`. In the app: **Settings → Locations** (or default location) and add that folder as a library root.

Failed downloads (404, HTML interstitial, checksum mismatch, etc.) are **skipped with a warning** — generated comics/PDF still complete so setup stays usable.

EPUBs come from the [IDPF/W3C EPUB 3 Samples](https://idpf.github.io/epub3-samples/30/samples.html) `20230704` release (reading-system test pubs) — not Project Gutenberg or Standard Ebooks.

## Layout (after setup)

```
demo/
  .gitkeep
  LICENSE-SOURCES.md
  books/                       # IDPF/W3C EPUB 3 samples (flat)
  comics/
    FakeManga_Paged/           # generated paged PNGs + CBZ
    FakeWebtoon_LongStrip/     # generated tall strips + CBZ
    OpenComic_Paged/           # PD comic pages (folder + CBZ)
    OpenWebtoon_LongStrip/     # PD tall images as chapters
    MixedFormats_OneTitle/     # images, .cbz, .cbr, .pdf
    _sources/                  # raw downloads used to assemble open titles
```

Tree shape matches [GUIDE.md](./GUIDE.md) expectations: title folder → chapters as folders or single archive/PDF files.

## CBR

`MixedFormats_OneTitle/Ch03.cbr` is a public-domain Golden Age comic from the Internet Archive (RAR-based). It is opened through Yomikiru's bundled full 7-Zip backend; users do not need a system `unrar` installation. If the download fails, the script warns and continues; other formats still work.

## Regenerate

Re-run `pnpm demo:setup` anytime. Existing files with matching checksums are skipped. Delete `demo/` (keep or recreate `.gitkeep`) and re-run for a clean tree.
